# Инструменты разработки AGR Collision

Не входят в аддон. Всё запускается либо системным Python (есть numpy, scipy, PIL),
либо фоновым Blender:

    BL="C:/Program Files (x86)/Steam/steamapps/common/Blender/blender.exe"
    "$BL" -b --factory-startup --python-exit-code 1 --python <script>.py -- <args>

`WT` ниже — корень рабочей копии аддона (папка, внутри которой лежит
`xivgate_agr_collision`).

## Связь с открытым Blender

`bl.py` — клиент к аддону «MCP for Blender», который слушает 127.0.0.1:45876.
Инструменты MCP этой сессии не подходят: мост ждёт другой аддон и другой
протокол (он шлёт ответ без перевода строки). Использование:

    echo 'import bpy; print(len(bpy.data.objects))' | python bl.py
    python bl.py script.py          # выполнить файл в открытом Blender

## Тестовые меши

* `cube.npz` — башня из сцены пользователя (`Cube`), 1 050 вершин, 2 096 треугольников,
  замкнута, 0 неманифолдных рёбер. Ключи: `v`, `f` (мировые координаты, float64).
* `house.npz` — синтетический дом: полые стены 25 см, дверь, два окна, арка,
  ниша 12 см. Строится заново скриптом `house.py`.

## Прогон и замеры

* `dumpall2.py -- WT mesh.npz PREFIX` — декомпозиция; пишет `PREFIX_hulls.npz`,
  `PREFIX_thin.npz`, `PREFIX_invalid.npz`, печатает время, число хуллов,
  треугольники и предупреждения.
* `summary.py hulls.npz` — число хуллов и треугольников, распределение толщин,
  количество «полос» (длиннее 10 м и тоньше 20 см).
* `eval2.py mesh.npz hulls.npz --n 300000` — объёмные метрики через qhull и
  число оборотов: лишний объём вне исходника, недокрытие, пересечения.
* `verify2.py mesh.npz hulls.npz [probe]` — точечная проверка: точки на гранях
  хуллов, смещённые внутрь по нормали, и точное расстояние до поверхности
  исходника. Показывает настоящий выход за модель.
* `overlaps.py -- WT hulls.npz` — пересечения пар хуллов с глубиной, вершины
  округляются до float32, как при экспорте.
* `plan.py mesh.npz hulls.npz Z CX CY HALF out.png` — сечение в плане:
  контур исходника белым, контуры хуллов цветом. Лучший инструмент для
  разбора «почему здесь столько кусков».
* `render.py -- hulls.npz OUT hulls|source [extra.npz]` — три ракурса в
  Workbench, каждый хулл своим цветом. `render_zoom.py` — крупный план.
* `prof.py -- WT mesh.npz out.prof` — cProfile прогона.

## Разбор причин

* `mergewhy.py -- WT mesh.npz` — по каждой паре соседей, у которых объединение
  почти выпуклое, печатает причину отказа склеивания.
* `pairwhy.py -- WT mesh.npz "x,y,z"` — трасса разрезов вокруг точки и
  подробности отказов для конкретных пар.
* `fallbackstat.py -- WT mesh.npz` — сколько разрезов сделано плоскостями
  граней, сколько запасными плоскостями, сколько отклонено.
* `absorbcheck.py -- WT mesh.npz` — аудит поглощений оболочкой плотной
  проверкой по числу оборотов.
